Cindy Linh Dang portfolio

To publish on GitHub Pages:
1. Put everything in this folder at the top level of your cindylinh.github.io repository.
2. Add your CV as Cindy_Dang_CV.pdf in the same folder (the Download CV buttons point to it).
3. Commit and push. The site appears at https://cindylinh.github.io

To add your Tableau Public dashboard:
Open katherine.html, find the line  const TABLEAU_URL = "";  and paste your Tableau Public link between the quotes.
